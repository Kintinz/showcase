REPO KINTINZ / SHOWCASE

Kết nối GitHub

Dùng token của chính bạn. Tài khoản cần có quyền ghi repo để đăng hoặc xóa giao diện. Chọn hướng dẫn phù hợp bên dưới.

Bạn là người được thêm vào repo Kintinz/showcase

Tạo token classic trên GitHub ↗

  1. Đăng nhập đúng tài khoản đã được cấp quyền ghi repo và đã chấp nhận lời mời.
  2. Nhập Note, ví dụ Showcase.
  3. Chọn Expiration, ví dụ 30 ngày.
  4. Trong Select scopes, tích public_repo.
  5. Nhấn Generate token, sao chép token vừa tạo.
  6. Quay lại Showcase, dán token vào ô bên dưới và nhấn Kết nối.

Token classic với scope public_repo có thể truy cập các repo public khác mà tài khoản của bạn được phép ghi. Chọn thời hạn ngắn và thu hồi token khi không còn cần dùng.

Bạn là chủ repo Kintinz

Tạo fine-grained token cho Showcase ↗

  1. Trang tạo token điền sẵn tên Showcase, Resource owner: Kintinz và thời hạn 30 ngày.
  2. Trong Repository access, chọn Only select repositories, rồi chọn showcase.
  3. Kiểm tra Contents: Read and write, Actions: Read và Metadata: Read.
  4. Nhấn Generate token, sao chép token rồi quay lại Showcase để kết nối.

Mặc định, tải lại trang trong cùng tab không cần nhập token. Tích ghi nhớ để kết nối lại khi mở website lần sau trên thiết bị này. Chỉ dùng tùy chọn này trên máy cá nhân: JavaScript cùng origin có thể đọc token đã lưu. Nhấn Ngắt kết nối để xóa token khỏi trình duyệt.
